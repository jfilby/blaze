Blaze

An AI compiler to generate assembly from traditional source.

What is Blaze?

Blaze is a compiler that takes traditional source code — today, TypeScript — and lowers it through a rule-based pipeline to native machine code. Large language models verify each stage of the pipeline and propose fixes, but they do not implement fixes themselves: a rule-based compiler inspects the model's proposals and applies them only when they are valid.

The compiler's stages are source → IR → verified IR → target low-level code → verified target code → binary. LLMs verify both the IR and the low-level targets, which keeps every stage checkable rather than merely plausible.

Blaze links the facil.io HTTP runtime beside programs that serve HTTP, and SQLite beside programs that store data. This website is itself a Blaze program: it is compiled to a native binary, serves its own pages over HTTP, and saves every chat to a SQLite database.

Stages

  1. Original source (e.g. TypeScript)
  2. IR (intermediate representation)
  3. Verified or revised IR (LLM-checked)
  4. Target low-level code (e.g. machine code)
  5. Verified or revised target code (LLM-checked)
  6. Binary
